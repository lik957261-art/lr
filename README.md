# LR Entry

Personal bookmark for a self-hosted Loomrail instance:
https://lik957261-art.github.io/lr/

This static page redirects to a verified HTTPS endpoint. It does not host
Loomrail, proxy conversations, collect passwords, or store access keys.
Authentication happens only on the destination Synology host.

The local publisher updates route.json after checking the current route.
Expired, invalid, or unexpected destinations are rejected by the page.
